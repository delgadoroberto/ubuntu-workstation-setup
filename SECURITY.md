# Security Policy

## Supported Versions

This project is a documentation and workstation setup repository. Security-related issues should be reported for the currently maintained documentation and configuration.

## Reporting a Vulnerability

If you discover a security issue in this repository, please do not disclose sensitive details publicly through a GitHub Issue.

Instead, report the issue privately through the repository's available security reporting mechanisms.

When reporting an issue, please include:

- A description of the issue.
- The affected file or configuration.
- Steps to reproduce the issue, when applicable.
- The potential security impact.
- Any suggested remediation.

Please allow reasonable time for the issue to be reviewed before publicly disclosing details.

## Scope

Security reports may include:

- Unsafe commands or configurations.
- Incorrect firewall or security settings.
- Insecure default configurations.
- Commands that may unintentionally expose sensitive information.
- Configuration examples containing security weaknesses.

This policy does not cover general documentation errors or feature requests.
