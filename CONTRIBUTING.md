# Contributing

Thank you for your interest in contributing to Ubuntu Workstation Setup.

Contributions are welcome, especially improvements to documentation, installation procedures, configuration examples, troubleshooting steps, and compatibility with supported Ubuntu releases.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test commands and configuration changes when possible.
5. Ensure Markdown follows the repository's linting rules.
6. Commit your changes with a clear message.
7. Open a Pull Request.

## Contribution Guidelines

- Keep documentation clear, concise, and technically accurate.
- Prefer commands that are appropriate for supported Ubuntu releases.
- Explain potentially disruptive commands before recommending them.
- Do not include credentials, secrets, personal data, or machine-specific information.
- Avoid unnecessary changes outside the scope of the contribution.
- Update related documentation when changing an existing procedure.

## Pull Requests

Pull Requests should include:

- A clear description of the change.
- The reason for the change.
- Any relevant testing or verification performed.
- Documentation updates when applicable.

All contributions are reviewed before being merged.
